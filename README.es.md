## Acerca de dabetai

**dabetai** es un ecosistema preventivo integral para la diabetes que predice complicaciones como retinopatía, nefropatía, neuropatía y pie diabético antes de que sean irreversibles.

Este repositorio contiene la **Página de Aterrizaje** — el sitio web oficial de presentación diseñado para informar y motivar a los usuarios a conocer el ecosistema, destacando:

- Descripción general del proyecto y sus beneficios
- Acceso rápido a la app móvil y portal web
- Funcionalidades clave y ventajas tecnológicas
- Cómo los wearables y la IA se integran para la prevención

## Inicio rápido

### Prerrequisitos

- Node.js 18+
- pnpm

### Instalación

```bash
git clone https://github.com/dabetai-org/landing.git
cd landing
pnpm install
pnpm astro dev
```

El sitio estará disponible en `http://localhost:4321`
